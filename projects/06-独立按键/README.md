# 06 · 独立按键

[实验索引](../README.md) · [引脚映射](../../docs/04_引脚映射.md)

## 实验目标
读取独立按键，理解输入电平、消抖和按下/松开事件。

## 使用硬件与引脚连接
P4.2/P4.3/P3.2/P3.3 连接独立按键；具体响应看 `main.c`。P3.2/P3.3 还可复用为外部中断输入。

## 核心原理与程序流程
`main.c` 调用 `Int_Key` 的按键读取接口，根据返回值执行实验逻辑；消抖由接口实现和延时共同影响。

## 代码结构
`src/Int/Int_Key.c/.h` 是按键层，`src/Com` 是公共延时与类型，`src/main.c` 是任务入口。

## 编译与烧录
EIDE/Keil_C51 Build 得到 `build/Release/` HEX，按[指南](../../docs/06_编译与烧录.md)核对端口再烧录。

## 实验现象与调试记录
预期按键操作引起程序中的对应变化；未实测。若重复触发，区分按下电平、机械抖动和按住连续轮询。

## 本节知识点
输入口、上拉、消抖及事件边界。
