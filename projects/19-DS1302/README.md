# 19 · DS1302 时钟综合实验

[实验索引](../README.md) · [调试记录](../../docs/07_调试记录.md)

## 实验目标
读取 RTC 日期时间，并与 DS18B20 温度一起显示在 OLED 上。

## 使用硬件与引脚连接
DS1302：P3.7 SCLK、P4.0 IO、P4.1 RST；DS18B20：P4.4；OLED：P1.6/P1.7。依据[板级映射](../../docs/04_引脚映射.md)核对实物。

## 核心原理与程序流程
`main.c` 构造日期初值、初始化 OLED/DS1302 并调用 `Int_DS1302_SetDate`；循环读取 RTC、温度，格式化日期和时间字符串显示在 OLED 两行。

## 代码结构
`Int_DS1302` 为 RTC 接口；`Int_DS18B20` + `Dri_1Wire` 获取温度；`Int_OLED` + `Dri_IIC` 显示；`main.c` 完成综合业务。

## 编译与烧录
EIDE/Keil_C51 Build，核对 HEX 后烧录；RTC 与 OLED 电源/接线应先确认。[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期 OLED 显示日期、星期、时间和温度；未实测。原程序每次上电都会设置示例时间，且温度读取有转换等待疑点；二者见[调试记录](../../docs/07_调试记录.md)。

## 本节知识点
RTC 串行接口、日期时间结构、字符串格式化和多外设集成。
