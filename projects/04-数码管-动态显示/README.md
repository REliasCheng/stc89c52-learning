# 04 · 数码管动态显示

[实验索引](../README.md) · [已知问题](../../docs/07_调试记录.md)

## 实验目标
通过快速逐位扫描显示多位数字，理解消影。

## 使用硬件与引脚连接
P0 段码，P1.3–P1.5 选择 74HC138 位地址，P3.6 数码管使能；参见[引脚表](../../docs/04_引脚映射.md)。

## 核心原理与程序流程
先把数字写入 `buffer[8]`，循环清 P0、换位、送段码并短暂保持；主循环不断调用 `DigitalTube_Refresh()`。

## 代码结构
`src/main.c` 集中实现显示，`.eide/eide.json` 为 EIDE 配置，尚未拆成 `Int` 模块。

## 编译与烧录
EIDE 使用 Keil_C51 Build，输出 `build/Release/`；核对当前端口和 HEX 再下载。[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期显示 `1234567`；未实测。原文件将 `u16` 定义为 `unsigned char`，与延时参数命名不符，保持原样并列入[待验证记录](../../docs/07_调试记录.md)。

## 本节知识点
动态扫描、消影、段码缓冲及刷新频率。
