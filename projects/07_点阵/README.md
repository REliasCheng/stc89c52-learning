# LED 点阵｜74HC595 扫描与滚动显示

[返回项目模块](../README.md) · [板卡引脚](../../hardware/引脚映射.md) · [课程工程](src/course/)

[12 点阵 LED](src/course/12-点阵LED/)显示固定八字节图案；[13 滚动显示](src/course/13-点阵LED-滚动显示/)将较长图案逐列移入显示缓冲。一个快节拍负责重复扫描，另一个慢节拍推进画面。

## 74HC595 与点阵

控制链路：P1.0 SER → 74HC595 串行数据；P1.2 SCK → 移位时钟；P1.1 RCK → 输出锁存。点阵数据由 P0 输出，P3.5 控制点阵使能。74HC595 把少量控制线扩展成点阵行选择相关信号，P0 提供当前扫描位置的数据。P0 与 LED/数码管共线，因此应先确认点阵使能状态，再分析图案数据。

## 两条时间线

两个工程都先由 Int_LEDMatrix_Init 注册 Timer0 刷新回调。Timer0 ISR → Dri_Timer0 回调表 → Int_LEDMatrix_RefreshByTimer0 → 74HC595/P0 是持续扫描路径。12 工程的 main 只调用一次 SetPic 设置显示缓冲；13 工程的 main 每约 200 ms 调用 Shift，将 picture 数组中的一列推进缓冲。这两个时间线分别控制“看得见”和“内容在移动”。

### 缓冲与扫描函数

- **SetPic(pic)**：将八字节图案作为显示缓冲，避免主循环逐次操作扫描行。
- **RefreshByTimer0()**：每次节拍处理下一扫描位置，并通过 74HC595 的移位、锁存动作更新选通；P0 输出当前数据的取反值，体现板上有效电平。
- **Shift(picture[i])**：把新列推入缓冲，更新的是画面内容，不承担高频刷新。
- 13 工程的 picture 为 26 字节，滚动节奏由主循环延时控制；不能拿这个 200 ms 延时当作点阵扫描周期。

## 扫描方向与时序

点阵把端口复用、串并转换、显示缓冲和定时回调放在同一工程。若画面不稳，先区分刷新节拍与内容更新节拍；若方向不符，再核 74HC595 信号顺序、P0 极性和图案字节位序。定时回调负责高频扫描，主循环只在较慢节拍下推进图案内容。

## 点阵检查

建议按“P3.5 使能 → Timer0 回调 → SER/SCK/RCK 移位与锁存 → P0 数据 → 图案缓冲”排查。静态图正常而滚动异常时，重点看 Shift 与 26 字节索引；两者都异常时，先看共享硬件路径。[时间关系笔记](notes/)记录了两版本差异，图案朝向仍应以实际板卡观察补充。
