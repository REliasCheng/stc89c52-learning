# LED 读码记录

- [最小点灯 `main.c`](../src/course/00-点亮LED/main.c) 只写 `P00 = 0`，然后停在死循环。这比先看一大段初始化代码更适合检查 GPIO、烧录链路和 LED 极性。
- [流水灯](../src/course/02-LED-流水/main.c) 把 `tmp` 从 `0x01` 左移到溢出，再回到 `0x01`；`P0 = ~tmp` 表明这里不能用“1 一定点亮”的直觉看端口值。
- 延时函数标注 11.0592 MHz。换晶振、12T 设置后，肉眼看到的节奏不能直接照搬。
