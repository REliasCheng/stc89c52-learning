# 01 · LED 闪烁

[实验索引](../README.md) · [引脚映射](../../docs/04_引脚映射.md)

## 实验目标
用延时实现最基本的周期性输出。

## 使用硬件与引脚连接
STC89C52RC、11.0592 MHz 晶振；P0.0 为 LED 数据，P3.4 控制 LED 使能。以[扩展板图](../../resources/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)为准。

## 核心原理与程序流程
`main()` 循环取反 `P00`，调用 `Delay500ms()`；延时与实际晶振/机器周期相关。

## 代码结构
根目录 `main.c`、`STARTUP.A51`、`01-LED-闪烁.uvproj`，保留原 Keil 工程相对路径。

## 编译与烧录
Keil Build，在 `Objects/` 找 HEX；核对 STC89C52RC 和当前 COM 口后用 STC-ISP 下载。[操作指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期单颗 LED 周期闪烁，整理时未复测；频率不符时先检查时钟、12T、延时实现。

## 本节知识点
循环、位取反、阻塞式延时和硬件使能。
