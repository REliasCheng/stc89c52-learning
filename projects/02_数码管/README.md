# 02 · 数码管：段码与位选是两回事

[实验目录](../README.md) · [引脚表](../../hardware/引脚映射.md)

这组三步最值得连着看：[静态显示](src/course/03-数码管-静态显示/)、[动态扫描](src/course/04-数码管-动态显示/)、[模块化版本](src/course/05-数码管-模块化编程/)。静态例子里 `P1.3–P1.5` 经 74HC138 选中某一位，`P0` 再送共阴数码管段码；动态例子把每位段码放到缓冲区，不断刷新；最后一个把接口移进 `Int_DigitalTube`。

`04` 的 `u16` 在原文件中实际定义为 `unsigned char`，与名称不符。这里保留原样，不能把本组当成已经修复过的驱动。[读码笔记](notes/)记录了这一点及消影顺序。

**当前进度：**三个工程可作为对照材料；显示亮度、位序和消影效果仍待实物复现。`03` 使用旧版 `.eide/eide.yml`，后两份为 `.eide/eide.json`，打开时先看[开发环境](../../docs/开发环境.md)。
