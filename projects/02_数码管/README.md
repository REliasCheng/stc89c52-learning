# 数码管｜段码、位选与动态扫描

[返回项目模块](../README.md) · [板卡引脚](../../hardware/引脚映射.md) · [课程工程](src/course/)

三个工程把显示控制逐步展开：[03 静态显示](src/course/03-数码管-静态显示/)负责选中一位并输出段码；[04 动态显示](src/course/04-数码管-动态显示/)加入八位缓冲与循环扫描；[05 模块化编程](src/course/05-数码管-模块化编程/)把显示操作移入 Int_DigitalTube。重点不是显示一个数字，而是在有限 IO 下把“选哪一位”与“这一位显示什么”分离。

## 段选与位选

位选路径：STC89C52RC P1.3–P1.5 → 74HC138 → 数码管各位选通。段码路径：P0 → 74HC245 → 段线。P3.6 控制数码管显示使能。译码器用三根选择线覆盖八位，74HC245 缓冲共享的 P0 数据线。P0 同时参与 LED/点阵，因而必须先辨认当前被使能的是哪组外设。本板图是 74HC138/74HC245 方案，不应套用其他教学板的 74HC573 锁存器接法。

## 扫描代码

静态版由 main 选位、查段码并直接写端口。动态版把各位内容放在八字节 buffer，主循环反复刷新。模块化版的调用变为 main → Int_DigitalTube 初始化/设置数字/刷新 → P1/P0 硬件输出。04 和 05 的 EIDE 配置与 03 的旧版 eide.yml 不同，编译时按各自工程打开。

### 关键代码

- **position <<= 3**：将 0–7 的数字位号移动到 P1.3–P1.5 对应的位域；随后 P1 &= 0xC7 清掉旧选择，再写新位号。
- **P0=num_code**：段码决定当前选中的那一位亮哪些段，不能拿它代替位选。
- **buffer[8] 与刷新函数**：应用修改显示内容，刷新例程逐位读缓冲。换位前先清 P0，可减少旧段码落在新位上的残影。
- 04 的源码把名为 u16 的类型定义为 unsigned char；延时参数可能被截断。这是该版本原始写法，阅读时应按实际类型推导。

## 刷新时序

动态扫描依赖持续刷新：扫描太慢会闪烁，位选与段码交接不干净会串位，P3.6 状态不对则可能整屏不亮。Int_DigitalTube 封装位选、段码和刷新后，main 只更新显示内容。

## 显示检查

复现时可按“P3.6 使能 → P1 位选 → P0 段码 → buffer 内容 → 刷新循环”的顺序定位。乱码先核段码表和位号，重影再看换位前清屏动作；不同版本的 u16 定义要分开看。这里是基于工程的排查路径，不将源码风险描述为已经出现的板上故障。[读码笔记](notes/)保留版本细节。
