# 看数码管代码时记下的三件事

1. [静态例子](../src/course/03-数码管-静态显示/src/main.c) 先写 P1 位地址，再用 P0 送 `codes[6]`；调用 `DisplaySingle(7, ...)`，所以别把“第 7 位”与数组第 7 项混淆。
2. [动态例子](../src/course/04-数码管-动态显示/src/main.c) 换位前先把 P0 清零，这是为了减少残影；如果主循环不持续刷新，多位数字不会稳定留在屏上。
3. `typedef unsigned char u16;` 是动态例子的原样代码。它实际只有 8 位，`Delay1ms(u16 count)` 的大参数会截断；待能编译并在板上量测时再单独修订，不偷偷改课程快照。

下一次实测应记录每位段码、实际位序、刷新频率和关闭 LED/点阵使能后的效果。
