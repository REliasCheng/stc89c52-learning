# 09 · 外部中断

[实验索引](../README.md) · [调试记录](../../docs/07_调试记录.md)

## 实验目标
体验按键触发的 INT0 外部中断和中断服务程序。

## 使用硬件与引脚连接
P3.2/INT0 接教学板对应按键；LED 显示相关端口参见 `main.c` 与[引脚表](../../docs/04_引脚映射.md)。

## 核心原理与程序流程
`INT0_Init()` 配置触发与使能，主循环保持运行，INT0 入口响应边沿并执行示例处理。

## 代码结构
`src/main.c` 包含初始化和 ISR；`src/Com` 提供延时。尚未抽出单独中断驱动。

## 编译与烧录
EIDE/Keil_C51 Build，确认新 HEX 和端口后下载。[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期按键触发源码指定输出变化；未实测。原 ISR 中有 10 ms 阻塞消抖，教学上直观但不宜照搬到高实时性程序。

## 本节知识点
INT0、触发方式、ISR 执行时间与消抖取舍。
