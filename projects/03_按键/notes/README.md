# 按键事件与扫描记录

- [独立按键 `main.c`](../src/course/06-独立按键/src/main.c) 每轮依次检查四个接口，返回真就取反对应 LED。需要观察“按住不放”是否只翻转一次，以及消抖会不会影响快速连按。
- [矩阵工程](../src/course/07-矩阵按键/src/main.c) 把键号交给 `Int_DigitalTube`，因此它同时依赖显示刷新；若按键响应迟缓，应区分扫描问题与显示/延时阻塞。
- 独立键使用 P4.2/P4.3/P3.2/P3.3；矩阵行列用 P2。P3.2 也可作 INT0，下一章会碰到这个复用关系。

我将低电平检测、10 ms 消抖、等待松开和矩阵行列定位视为同一条输入路径。后续观察连按或长按时，应将输入波形、接口返回值和数码管反馈放在同一时间线上记录。
