# 03 · 按键：从四个独立输入到行列扫描

[实验目录](../README.md) · [按键引脚](../../hardware/引脚映射.md)

[独立按键](src/course/06-独立按键/)让四个按键分别切换 P0 上的四个 LED；`main.c` 不直接处理抖动，而是调用 `Int_Key_IsSW1Pressed()` 等接口。[矩阵按键](src/course/07-矩阵按键/)把输入扩成行列扫描，并把检测到的键号交给数码管显示。

## 从一个输入到 4×4 扫描

独立键接在 P4.2/P4.3/P3.2/P3.3。`Int_Key_IsSWxPressed()` 先检测低电平，延时 10 ms 再确认，随后 `while (SWx == 0)` 等松开；`main()` 取反对应的 P0 LED。矩阵键改用 P2.0–P2.3 逐行输出 `0xFE/0xFD/0xFB/0xF7`，读 P2.4–P2.7 的列，返回 `5 + j + 4 * i`，再交给 `Int_DigitalTube` 显示键号。

我从这里认识到“按键事件”不是一次读取电平：消抖、等待释放和行列定位共同决定什么时候算一次输入。矩阵工程还同时刷新数码管，所以排查迟缓响应时要把扫描、10 ms 等待和显示循环分开。P3.2 在下一章又成为 INT0，体现同一引脚的功能复用。两份原课程工程与[读码笔记](notes/)可追溯；仓库没有留存按键手感或长按次数的测试视频，不把函数名当实测结论。
