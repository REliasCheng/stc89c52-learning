# 按键｜独立输入与矩阵扫描

[返回项目模块](../README.md) · [板卡引脚](../../hardware/引脚映射.md) · [课程工程](src/course/)

[06 独立按键](src/course/06-独立按键/)把四个开关分别映射到 LED 状态切换；[07 矩阵按键](src/course/07-矩阵按键/)通过行列扫描识别键号，并在数码管上显示。两者让输入处理从“读取一个电平”进阶为“确认一次按键事件，再交给应用”。

## 按键连接

独立键分别连 P4.2、P4.3、P3.2、P3.3，按下后为低电平；P0 输出 LED。矩阵键使用 P2.0–P2.3 作逐行驱动，P2.4–P2.7 作列输入，形成 4×4 交叉点。矩阵工程的显示另走 P1.3–P1.5 → 74HC138 位选、P0 → 74HC245 段码。P3.2 在后面的外部中断工程改作 INT0，展示同一物理引脚的功能转换。

## 扫描流程

独立键的调用链是 main → Int_Key_IsSWxPressed → 消抖与释放判断 → main 切换相应 LED。矩阵工程则是 main → Int_KeyMatrix_CheckSW → 行列扫描与键号计算 → Int_DigitalTube 设置/刷新数字。输入接口返回的是应用可用的事件或编号，显示与 LED 输出不写进按键扫描的底层动作中。

### 关键函数

- **Int_Key_IsSWxPressed()**：先发现低电平，延时约 10 ms 后复核，再等待松开；“按下并松开”才作为一次输入反馈给 main。
- **0xFE/0xFD/0xFB/0xF7**：四种行输出模式，每轮只让目标行处于有效状态。
- **0x10/0x20/0x40/0x80**：检测四根列线的状态。行 i、列 j 被定位后，函数按 5+j+4*i 计算返回键号。该编号策略属于当前工程，不能直接套到其他键盘布局。

## 事件边界

独立键的等待释放是简单可靠的事件边界，但会阻塞主循环；矩阵键需要先确认行列方向，再避免扫描期间的电平扰动。main 只接收键值，消抖、行列扫描和编号计算留在输入接口中。

## 输入检查

键号错乱可按 P2 行输出、列输入、计算公式、显示接口逐层检查；按键重复触发先看消抖和释放等待。对独立键，P3.2 同时具备 INT0 功能，但本工程作为普通 IO 读取，不能把后续中断配置误套进来。[读码笔记](notes/)记录这两种输入方式的对照。
