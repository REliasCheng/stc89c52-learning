# 03 · 按键：从四个独立输入到行列扫描

[实验目录](../README.md) · [按键引脚](../../hardware/引脚映射.md)

[独立按键](src/course/06-独立按键/)让四个按键分别切换 P0 上的四个 LED；`main.c` 不直接处理抖动，而是调用 `Int_Key_IsSW1Pressed()` 等接口。[矩阵按键](src/course/07-矩阵按键/)把输入扩成行列扫描，并把检测到的键号交给数码管显示。

这两份仍是课程源码。按下、松开和长按究竟各触发几次，要到板上实测，不能从函数名直接断言。[笔记](notes/)列了我准备检查的现象。当前没有录制按键演示。
