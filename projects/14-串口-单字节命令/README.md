# 14 · UART 单字节命令

[实验索引](../README.md) · [调试记录](../../docs/07_调试记录.md)

## 实验目标
接收一个串口命令字节，控制 LED 并回复结果。

## 使用硬件与引脚连接
P3.0 RXD / P3.1 TXD 接 USB 串口链路；LED 使用 P0/P3.4。使用共地且确认串口电平和 CH340K 端口。[引脚表](../../docs/04_引脚映射.md)。

## 核心原理与程序流程
Timer1 自动重装提供 UART 波特率；UART 模式 1 的 RI/TI 中断更新收发状态，`main.c` 根据接收命令控制 LED、回复成功或错误文本。

## 代码结构
`Dri/Dri_UART` 封装初始化/发送/接收和 ISR；`main.c` 是命令业务；`Com` 为基础类型/延时。

## 编译与烧录
EIDE/Keil_C51 Build；烧录后再打开串口监视器测试，避免端口同时被烧录器占用。[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期单字节命令可开/关 LED 并返回字符串；未实测。原代码启用 `ET1` 但没有 Timer1 ISR，且 `0x00` 不能作为有效接收事件，详见[疑点](../../docs/07_调试记录.md)。

## 本节知识点
UART 帧、波特率、Timer1、串口中断与应答。
