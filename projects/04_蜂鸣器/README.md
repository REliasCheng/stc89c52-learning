# 04 · 蜂鸣器：给按键一个声音反馈

[实验目录](../README.md) · [接线](../../hardware/引脚映射.md)

这组只有[一个课程工程](src/course/08-蜂鸣器/)：矩阵按键检测到键值后，`main.c` 先调用 `Int_Buzzer_Buzz()`，再把键号送去数码管；循环末尾继续刷新显示。蜂鸣器在 P4.6，矩阵键和数码管分别占用 P2 与 P0/74HC138。

## 一次输入牵动两个输出

这套连接是 `P2 矩阵键 → Int_KeyMatrix → main → Int_Buzzer/P4.6`，键号另经 `Int_DigitalTube` 送往 P0 段线与 P1 位选。[扩展板图第 9 页](../../hardware/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)还显示 P4.6 经三极管驱动蜂鸣器，而非 IO 口直接承受负载。`Int_Buzzer_Buzz()` 循环 100 次，每次翻转 P4.6 并延时 1 ms；`main()` 等发声函数返回后才更新数字，循环末尾继续刷新数码管。代码因此展示了输入、声音和显示的组合，也暴露阻塞式发声与动态显示的时间竞争。

我的工程判断是先分清“蜂鸣器有没有被切换”和“显示有没有按时刷新”：若出现显示闪烁，应该沿主循环耗时排查，而不急着改段码。课程工程及[观察点](notes/)已归档；仓库没有当时的音频或定量时长记录，因此不写具体响度或实测频率。
