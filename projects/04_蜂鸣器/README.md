# 04 · 蜂鸣器：给按键一个声音反馈

[实验目录](../README.md) · [接线](../../hardware/引脚映射.md)

这组只有[一个课程工程](src/course/08-蜂鸣器/)：矩阵按键检测到键值后，`main.c` 先调用 `Int_Buzzer_Buzz()`，再把键号送去数码管；循环末尾继续刷新显示。蜂鸣器在 P4.6，矩阵键和数码管分别占用 P2 与 P0/74HC138。

这里的重点不是“会响”三个字，而是一次按键同时驱动声音和显示时，阻塞式发声是否拖慢数码管刷新。[笔记](notes/)写了复现时要分开观察的两件事。当前只有课程源码，没有本人的音频或实物测试记录。
