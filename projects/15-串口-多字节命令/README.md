# 15 · UART 多字节命令

[实验索引](../README.md) · [UART 单字节](../14-串口-单字节命令/README.md)

## 实验目标
接收字符串命令并用空闲时间判定一帧结束。

## 使用硬件与引脚连接
P3.0/P3.1 为 UART，P0/P3.4 控制 LED；串口地线、设备和端口按[引脚表](../../docs/04_引脚映射.md)确认。

## 核心原理与程序流程
UART ISR 逐字节装入 `s_buffer[16]`；Timer0 回调累计空闲时间，将缓冲标记为完整；`main.c` 比较命令并回复。

## 代码结构
`Dri_UART` 处理帧收发，`Dri_Timer0` 调度接收超时回调，`main.c` 解析业务命令；`Com` 为公共函数。

## 编译与烧录
EIDE/Keil_C51 Build，核对 HEX、端口后烧录，关闭烧录器再用串口监视器发送命令。[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期完整命令控制 LED、收到文本回复；本次未复测。原接收数组未做长度上限保护，不要用超过缓冲长度的数据测试正式硬件；这是[待修复项](../../docs/07_调试记录.md)。

## 本节知识点
接收缓冲、帧边界、Timer0 回调与安全边界。
