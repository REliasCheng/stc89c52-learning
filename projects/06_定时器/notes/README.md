# 从 Timer0 中断到回调

- [10 工程](../src/course/10-定时器/src/main.c) 的 `main()` 只初始化 `Dri_Timer0`，之后保持空循环。要找 LED 为什么变化，应进入驱动的 ISR，而不是在 `main()` 里找延时。
- [11 工程](../src/course/11-定时器封装/src/main.c) 注册 `LED_Blink`；驱动持有回调，应用决定 LED 行为。阅读后续点阵工程时可沿“Timer0 → 回调 → 显示刷新”追踪。
- 周期计算依赖 11.0592 MHz 与 12T。文档中的周期由计数/重装值推导，板端波形可按调试步骤测量。

这两个工程的持续行为位于 ISR 和回调中：10 工程需要进入 ISR 查找动作，11 工程还需要检查已注册的回调。分析点阵刷新或 UART 接收超时时，可先画出调用链，再确认负责计时的层级。
