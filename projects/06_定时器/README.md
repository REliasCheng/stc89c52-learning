# 06 · 定时器：把计时从主循环搬出去

[实验目录](../README.md) · [工程分层](../../docs/工程结构.md)

[Timer0 初版](src/course/10-定时器/)由 `Dri_Timer0` 配置和处理中断；[封装版](src/course/11-定时器封装/)增加 `Dri_Timer0_RegisterCallback(LED_Blink)`，把“多久执行一次”与“执行什么”拆开。这也是后面点阵刷新、UART 帧结束判断复用定时器驱动的起点。

## 时间基准如何变成接口

两个版本都用 STC89C52RC 的 Timer0，按 11.0592 MHz/12T 配置模式 1，向 TH0/TL0 装入 `64614` 并在 `interrupt 1` 中重装。10 工程的 ISR 自己累积 `count`、每 500 次翻转 P0.0；11 工程则把 `LED_Blink` 注册到最多四个回调槽，由 Timer0 ISR 逐个调用。调用链从 `main → Dri_Timer0` 进一步变成 `main 注册任务 → Timer0 中断 → 任务回调`。

我在这里理解到，定时器驱动不必知道应用要闪灯还是刷新点阵；它提供时间基准，应用通过回调决定行为。这也是后续点阵和 UART 空闲判断能复用同一机制的原因。10 工程 ISR 名里的 `Dir_` 与其余 `Dri_` 不一致，原样保留；周期计算与实测周期不能混为一谈。[读码笔记](notes/)记录了这两个版本，课程源码未被合并或修正。
