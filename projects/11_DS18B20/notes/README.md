# 温度读数检查

[原接口](../src/course/18-DS18B20/src/Int/Int_DS18B20.c) 依次发送 `0xCC`（跳过 ROM）、`0x44`（启动转换），随后立即重置总线、发送 `0xBE` 并读取两个字节。`main.c` 循环末尾的 500 ms 延时在**读取之后**，不能直接说它保证了本次转换完成。

对照[DS18B20 手册](../../../hardware/datasheets/DS18B20.pdf)可判断转换时间与读数解释；源码里缺少本次转换的等待，仓库也没有上电首读、室温或加热后的原始测量值。若修订等待逻辑，应保留课程版并单独给出测试证据。
