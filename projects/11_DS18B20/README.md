# 11 · DS18B20：温度转换不是“发完命令立刻读”

[实验目录](../README.md) · [引脚](../../hardware/引脚映射.md)

[18-DS18B20 示例](src/course/18-DS18B20/)把 P4.4 上的 1-Wire 温度读数显示到 OLED，主循环约每 500 ms 更新一次。调用链是 `main → Int_DS18B20 → Dri_1Wire`，显示走另一条 `Int_OLED → Dri_IIC`，比较适合练习跨接口追代码。

原温度函数发出转换命令后立即复位并读暂存器，没有明确等待**这一次**转换完成。我先保留原样，并把它列为[重点待测](notes/)；没有把屏幕显示出的数字当成测温准确的证据。
