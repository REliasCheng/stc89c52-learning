# 13 · 点阵 LED 滚动显示

[实验索引](../README.md) · [点阵基础](../12-点阵LED/README.md)

## 实验目标
在静态点阵基础上逐列送入图案，形成滚动效果。

## 使用硬件与引脚连接
沿用 P1.0/P1.1/P1.2 → 74HC595、P0 共享数据、P3.5 点阵使能；见[引脚表](../../docs/04_引脚映射.md)。

## 核心原理与程序流程
Timer0 保持显示刷新；主循环逐项 `Int_LEDMatrix_Shift(picture[i])`，每列延时约 200 ms 后继续，滚动内容由 `picture` 数组决定。

## 代码结构
`main.c` 保存图案序列；`Int_LEDMatrix` 维护显示缓冲与 595；`Dri_Timer0` 提供扫描时基。

## 编译与烧录
EIDE/Keil_C51 Build，检查新 HEX 后下载；见[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期点阵图案横向移动；未实测。区分“扫描刷新太慢”和“主循环移位太慢”两类闪烁/运动问题。

## 本节知识点
双时间尺度、显示缓冲与动态内容。
