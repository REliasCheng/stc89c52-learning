# 11 · 定时器封装

[实验索引](../README.md) · [工程结构](../../docs/05_工程结构.md)

## 实验目标
用回调让定时器驱动负责计时，应用层负责 LED 行为。

## 使用硬件与引脚连接
Timer0 属 MCU 内部资源；演示输出用 P0.0 LED，P3.4 LED 使能。见[板级映射](../../docs/04_引脚映射.md)。

## 核心原理与程序流程
`Dri_Timer0_Init()` 初始化后，`Dri_Timer0_RegisterCallback(LED_Blink)` 把 `main.c` 中的处理函数注册给定时器驱动，定时到达时更新 LED。

## 代码结构
`main.c` 定义业务回调；`Dri/Dri_Timer0` 封装寄存器和 ISR；`Com` 为公共辅助。比 10 工程更明确地区分任务层与驱动层。

## 编译与烧录
EIDE/Keil_C51 Build，检查本实验 HEX 后按[指南](../../docs/06_编译与烧录.md)烧录。

## 实验现象与调试记录
预期 LED 周期变化；本次未接板复测。若无响应，先确认回调注册、全局/Timer0 中断使能和 P3.4。

## 本节知识点
函数指针/回调、模块边界和可复用周期任务。
