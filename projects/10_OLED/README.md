# 10 · OLED：先把一行字显示出来

[实验目录](../README.md) · [接线](../../hardware/引脚映射.md)

[17-OLED 示例](src/course/17-OLED/)很直接：初始化、清屏，在第 0 行显示 `Hello World!`，第 1 行显示 `-12345678`。`Int_OLED` 负责命令、字符与数字显示，`Dri_IIC` 负责 P1.6/P1.7 上的总线动作；它与 AT24C02 共线，但器件地址不同。

## 显示接口如何建在总线之上

`P1.6/P1.7 → 软件 I²C → OLED`，与 EEPROM 共用两根线。`Int_OLED` 向总线发送 `0x78` 作为示例屏的**写控制字节**，随后用 `0x00`/`0x40` 区分命令与数据；`Init` 发送开屏和映射命令，`Clear` 清 128×8 页数据，`ShowStr` 把字符拆成上下两段 8 字节字模写入。`main()` 因此只需调用初始化、清屏、字符串和数字接口，不处理每个 I²C 电平。

我在这里看到分层的价值：屏幕黑了不能先怪 `Hello World!`，要从供电、共用总线、地址、初始化命令、字模和坐标逐层定位。`ShowNum` 还把整数转成字符串再交给 `ShowStr`，说明显示内容与传输机制可以分离。保留课程字库及[排查笔记](notes/)，不称其为我原创库，也不伪造 OLED 实拍；实际控制器型号应以手上器件标识核对。
