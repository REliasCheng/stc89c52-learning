# 10 · OLED：先把一行字显示出来

[实验目录](../README.md) · [接线](../../hardware/引脚映射.md)

[17-OLED 示例](src/course/17-OLED/)很直接：初始化、清屏，在第 0 行显示 `Hello World!`，第 1 行显示 `-12345678`。`Int_OLED` 负责命令、字符与数字显示，`Dri_IIC` 负责 P1.6/P1.7 上的总线动作；它与 AT24C02 共线，但器件地址不同。

这里先不把 OLED 字库做成一个新“个人库”。我想先确认屏幕型号、地址、初始化时序与实际显示方向，再记录自己的修改。[读码笔记](notes/)列了排查顺序。当前只有板卡资料渲染图，没有运行中的 OLED 实拍。
