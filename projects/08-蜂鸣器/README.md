# 08 · 蜂鸣器

[实验索引](../README.md) · [引脚映射](../../docs/04_引脚映射.md)

## 实验目标
由矩阵按键触发蜂鸣器并显示键值。

## 使用硬件与引脚连接
P4.6 控制蜂鸣器；矩阵按键 P2.0–P2.7；数码管使用 P0、P1.3–P1.5、P3.6。

## 核心原理与程序流程
读取按键后执行 `Int_Buzzer_Buzz()`，同时把键值送给 `Int_DigitalTube` 并持续刷新。

## 代码结构
`src/Int/Int_Buzzer`、`Int_KeyMatrix`、`Int_DigitalTube` 分别负责输出/输入/显示；`Com` 提供公共函数。

## 编译与烧录
EIDE/Keil_C51 Build，检查 `build/Release/` HEX，用[指南](../../docs/06_编译与烧录.md)选择当前串口烧录。

## 实验现象与调试记录
预期按键时听到声音、数码管显示键值；未实测。频率/时长受延时和时钟影响，先区分无声与音调不准。

## 本节知识点
方波、频率/占空比、输入与输出组合。
