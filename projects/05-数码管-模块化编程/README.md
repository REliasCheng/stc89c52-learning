# 05 · 数码管模块化编程

[实验索引](../README.md) · [工程结构](../../docs/05_工程结构.md)

## 实验目标
把数码管接口从 `main.c` 抽离，保留清晰的应用入口。

## 使用硬件与引脚连接
P0 段码、P1.3–P1.5 位选、P3.6 数码管使能；见[引脚表](../../docs/04_引脚映射.md)。

## 核心原理与程序流程
`Int_DigitalTube_Init()` 初始化，`DisplayNum(-2345678)` 写显示内容，主循环调用 `Refresh()` 保持动态显示。

## 代码结构
`src/main.c` 编排流程；`src/Int/Int_DigitalTube.c/.h` 实现设备接口；`src/Com/Com_Util.c/.h` 提供公共类型/延时。

## 编译与烧录
用 EIDE/Keil_C51 Build，确认 `build/Release/` HEX 和当前串口后烧录。[指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期显示带负号的示例数字；本次未实测。若闪烁，核对刷新循环是否持续运行及其他阻塞操作。

## 本节知识点
模块接口、头文件、调用关系和显示刷新。
