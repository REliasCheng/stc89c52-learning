# 02 · LED 流水

[实验索引](../README.md) · [引脚映射](../../docs/04_引脚映射.md)

## 实验目标
让多个 LED 按位依次变化，观察端口整体输出。

## 使用硬件与引脚连接
P0.0–P0.7 LED 数据，P3.4 LED 使能；核心板晶振 11.0592 MHz。见[扩展板 V1.0](../../resources/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)。

## 核心原理与程序流程
`main.c` 改变掩码 `tmp`，以 `P0 = ~tmp` 输出，穿插 `Delay100ms()`；按代码逻辑重复流水。

## 代码结构
根目录 `main.c`、`STARTUP.A51`、`02-LED-流水.uvproj`，仍是早期 Keil 平铺工程。

## 编译与烧录
Keil 打开 `.uvproj` Build，检查 `Objects/` 目标 HEX 后用 STC-ISP 下载。[操作指南](../../docs/06_编译与烧录.md)。

## 实验现象与调试记录
预期 LED 逐位移动，非本次硬件实测；若方向/亮灭与直觉相反，注意代码的 `~` 和板上低电平有效关系。

## 本节知识点
位掩码、端口极性、循环与延时。
