## 代码阅读记录

- 对照[数码管静态显示代码](../projects/02_数码管/src/course/03-数码管-静态显示/src/main.c)和[扩展板图](../hardware/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)，显示链路可拆为位选和段码：P1.3–P1.5 经过 74HC138 选择位置，P0 输出该位置的段码；动态显示进一步加入消影和周期刷新。[硬件分析](我的硬件理解.md)记录了对应关系。
- 比较[定时器初版](../projects/06_定时器/src/course/10-定时器/src/main.c)和[封装版](../projects/06_定时器/src/course/11-定时器封装/src/main.c)，前者的 `main()` 只初始化后空转，后者把 `LED_Blink` 注册为回调。查功能时要继续追到驱动和中断，而不能因为 `main()` 空着就以为没有动作。
- EEPROM 工程的调用链为 `main → Int_EEPROM → Dri_IIC`，软件 I²C 与分页存储在同一工程中完成。

调试时把“源码可读、Build 出 HEX、下载成功、板上现象正确”分成四个检查点，先确定故障所在环节，再处理对应的工具链或程序。

## 开发环境排障

- EIDE 调用的 Python 曾缺少 `serial` 模块；需要在**同一解释器**安装 `pyserial`，只在另一个 Python 里装包无效。
- CH340K 串口在不同连接中出现过 COM3/COM5；先核对设备管理器和硬件 ID，再决定上传端口，不能盲改配置。
- EIDE 的 `flash` 任务只是委派上传。遇到“无 HEX”时要先确认 Build 是否产出文件及 `build/Release/` 路径，再排查串口。

具体操作见[常见问题](常见问题.md)。调试条目记录实验编号、日期、板卡版本、构建/烧录结果和实际修改。
