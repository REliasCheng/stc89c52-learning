# 常见问题

[首页](../README.md) · [编译与烧录](06_编译与烧录.md) · [调试记录](07_调试记录.md)

**Q：EIDE 点“烧录”提示没有 `serial`？** 先看任务实际使用哪个 `python`，对同一解释器运行 `python -m pip install pyserial`，随后验证 `import serial`。仅在另一个 Python 环境安装不会解决问题。[共享烧录脚本](../tools/README.md)需要 pyserial。

**Q：Build 成功但找不到 HEX？** Keil 00–02 查 `Objects/`；EIDE 03–19 查 `build/Release/`，确认 `.eide` 目标的 `outDir`、当前工程名及生成时间。根 `.gitignore` 故意不跟踪 HEX；本地生成不代表 Git 中应该有它。

**Q：EIDE 的 flash 按钮到底做什么？** `.vscode/tasks.json` 调用 EIDE 命令，EIDE 再按 `.eide` 的 uploader 命令运行共享 `stcflash.py`。先分别确认构建、HEX 路径、Python、串口；不能只看按钮是否触发。

**Q：COM3/COM5 哪个正确？** 都不是固定答案。每次核对设备管理器里 CH340K 当前端口/硬件 ID，再到 EIDE 或 STC-ISP 选同一端口，关闭占用串口的监视器。

**Q：为何要设置 11.0592 MHz / 12T？** 原核心板资料给出 11.0592 MHz；课程的 Timer0 延时、Timer1 UART 波特率等按具体机器周期和晶振推导。换晶振或模式必须重新计算，而不是只改烧录器显示。

**Q：`STC89C5xRC.H` 找不到？** 检查 Keil C51 / STC 设备支持文件是否已正规安装，再核对 `.eide/eide.json` 或 `eide.yml` 内的旧绝对路径。不要从任意网站下载不明头文件覆盖工程。

**Q：为什么没有教材 PDF、录像、安装包或 HEX？** 本仓库优先展示可读、可迭代的实验工程；资料选择性收录板卡原理图与器件手册，课程视频、重复归档、安装器、预编译 HEX 和构建缓存没有复制。其来源与用途见 [参考资料](09_参考资料.md)。
