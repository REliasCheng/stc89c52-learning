## 可复现的主机测试

从仓库根目录执行：

```text
python scripts/run_host_tests.py --compiler gcc
python scripts/run_host_tests.py --compiler clang
```

脚本实际编译、链接并运行 `practice/core/terminal_app.c` 与 `practice/tests/test_terminal_app.c`，使用 C11 和严格警告选项。编译器不可用时脚本会失败，不会把语法检查冒充测试通过。Linux 上还可用 `--sanitize` 运行 ASan/UBSan；它们不能证明不存在全部未初始化读取。

## C51 目标构建与烧录

当前公开快照没有完整的 Keil/EIDE 工程、`REG52`/设备头文件、DS1302/EEPROM/OLED/按键等外部驱动或固件 HEX。`practice/c51/` 是适配源码，不构成可直接打开并构建的 C51 工程。本仓库没有可供下载的固件，也没有本次修复对应的烧录与板端运行证据。

如果以后在权利清晰的独立环境完成目标工程，应分别记录：工具链构建结果、HEX 来源、实际连接端口、烧录结果、板端观测。主机测试通过与上述任一步都不能互相替代。
