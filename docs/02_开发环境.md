# 开发环境

[首页](../README.md) · [编译与烧录](06_编译与烧录.md) · [FAQ](08_常见问题.md)

| 用途 | 组件 | 说明 |
| --- | --- | --- |
| 编辑/项目 | Windows、VS Code、EIDE | 03–19 有课程工程配置；03 为 `eide.yml` 旧格式，04–19 为 `eide.json` |
| 编译 | Keil C51 | 00–02 的 `.uvproj`；EIDE 的 `Keil_C51` 工具链也依赖本地 Keil，不是独立编译器 |
| 设备定义 | `STC89C5xRC.H` | 头文件由本地 Keil/STC 配置提供；EIDE 配置原路径为 `c:/Program Files/Keil_v5/C51/INC/STC`，换机器要核对 |
| 烧录 | STC-ISP 或 Python 3 + pyserial | EIDE 自定义命令引用 `../../tools/stcflash.py`；脚本属 GPL，详见 [说明](../tools/README.md) |
| 硬件 | 核心板 V1.0、扩展板 V1.0、USB 串口 | 实际端口和驱动以本机设备管理器为准 |

课程原 `.code-workspace` 曾指定 GBK，部分源码中文注释也是 GBK。本仓库为 GitHub 可读性，将这些源码注释无损转为 UTF-8，并同步改为 `files.encoding: utf8`；原始课程文件未动。EIDE 的用户上下文、日志和输出目录属于本机状态，已排除在 Git 之外。

安装器、Keil 授权工具、驱动包、课程视频均不在本仓库中；请使用正规来源和适用的许可证获取工具链。工程配置里的绝对 STC 头文件路径是历史环境假设，不是跨平台保证。建议先用 00 点灯验证 Keil 和 HEX，再用 03 验证 EIDE，最后处理烧录。
