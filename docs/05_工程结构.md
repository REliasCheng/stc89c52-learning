# 源码与工程结构

[首页](../README.md) · [学习路线](01_学习路线.md) · [编译与烧录](06_编译与烧录.md)

`00–02` 是 Keil 平铺工程：根目录 `main.c`、`STARTUP.A51`、`.uvproj`；编译输出默认 `Objects/`/`Listings/`，不进 Git。`03` 采用旧版 EIDE `.eide/eide.yml`，`04–19` 采用 `.eide/eide.json`；源码放在 `src/`，配套 `.code-workspace` 和 `.vscode/tasks.json`。所有课程源文件保持原位置和文件名，尤其是 `.h` 继续与对应 `.c` 同目录；没有强行制作空 `include/` 或改变 include 路径。

逐步形成的分层：

```text
src/main.c         应用入口、实验流程
src/Com/           基本类型、延时等公共辅助
src/Dri/           Timer0、UART、IIC、1-Wire 等底层驱动
src/Int/           数码管、按键、蜂鸣器、点阵、EEPROM、OLED、DS18B20、DS1302 接口
.eide/             工具链/输出/上传配置（保留 eide.json 或 eide.yml）
.vscode/tasks.json EIDE 命令入口；不是独立编译或烧录器
```

例：`16-EEPROM/src/main.c` 调 `Int_EEPROM` 读写，由 `Dri_IIC` 驱动 SDA/SCL，显示由 `Int_LEDMatrix` 与 Timer0 配合；`19-DS1302/src/main.c` 组合 `Int_DS1302`、`Int_DS18B20`、`Int_OLED`，OLED 借用 I²C、温度借用 1-Wire。每个实验自包含一份当时版本的模块，因此同名 `Com`/`Dri` 文件可能在不同章节渐进变化，不应盲目合并成同一套驱动。

原 `tools/stcflash.py` 在多个工程中重复，仓库只保留 [一份共享脚本](../tools/stcflash.py)，EIDE 配置的相对调用路径已调整，详情见 [更新记录](../CHANGELOG.md)。原 EIDE `STC` 头文件绝对包含路径仍需按机器检查。模板见 [templates/eide-c51](../templates/eide-c51/)，它是教学起点，不是可代替全部实验的公共库。
