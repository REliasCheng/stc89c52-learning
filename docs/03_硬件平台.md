# 硬件平台

[首页](../README.md) · [引脚映射](04_引脚映射.md) · [原理图](../resources/README.md)

本仓库依据[核心板 V1.0 原理图](../resources/schematics/core-board/SCH_51教学核心版V1.0_2024-05-20.pdf)与[扩展板 V1.0 原理图](../resources/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)。核心板为 STC89C52RC（图中 LQFP44）和 11.0592 MHz 晶振，扩展板配置 LED、数码管、按键、点阵、蜂鸣器、串口、EEPROM、OLED、温度传感器、RTC 等外围。文件名日期与图框修订日期可能不完全同义，版本以 V1.0 标注。

P0 是并行显示/LED 的共享数据口；需要结合 P34/P35/P36 的使能状态理解一个输出值到底驱动哪个模块。数码管位选由 P13–P15 送入 74HC138，LED 点阵数据经 P10/P11/P12 控制的 74HC595 移位/锁存。74HC245 作为板上总线缓冲/收发器，不能仅凭程序端口值推断外围电平；接线核验应看原理图相应页。软件 I²C 的 P16/P17 同时服务 EEPROM 与 OLED，总线上的设备由地址区分。

芯片资料入口见 [参考资料](09_参考资料.md)。仓库未收录 DS1302 独立数据手册，不能用课程代码取代原厂时序表。连接实体板前确认供电、板卡跳帽、串口电平、USB 串口芯片及器件型号；**当前仓库整理过程未进行带电实测**。
