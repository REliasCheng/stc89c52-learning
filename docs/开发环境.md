# 开发环境与依赖

[首页](../README.md) · [构建与验证](编译与烧录.md)

当前公开仓库的可复现入口是可移植终端核心的主机测试：需要 Python 3 与 GCC 或 Clang。命令、编译范围和验证边界见[构建与验证](编译与烧录.md)。主机测试使用 Fake Platform，不访问真实 RTC、温度传感器或 EEPROM。

`projects/13_环境与时钟信息终端/practice/c51/` 引用未分发的 C51 器件驱动和头文件。仓库不提供 Keil/EIDE 工程、STC 设备支持包、板卡图纸、器件 PDF、烧录脚本或 HEX；因此不能把打开此仓库视为可直接进行 C51 目标构建或烧录。

历史学习记录中出现的 EIDE、Keil、COM3/COM5 等信息是旧环境背景，不是当前公开工程的路径、默认配置或已验证操作结果。
