# 开发环境：仓库里有什么、还缺什么

[首页](../README.md) · [编译与烧录](编译与烧录.md)

`projects/*/src/course/` 保存的是独立工程，不是一个可以从仓库根目录一次 Build 的工程。00–02 是 Keil `.uvproj`；03 起有 EIDE 工程，03 的 `.eide/eide.yml` 还是旧格式，其余主要使用 `.eide/eide.json`。

| 组件 | 在这里的作用 |
| --- | --- |
| Windows + VS Code/EIDE | 打开 `.code-workspace`，选择 Keil_C51 目标，管理构建/上传 |
| Keil C51 | 真正的 8051 编译工具链；EIDE 配成 `Keil_C51` 仍依赖本地安装 |
| `STC89C5xRC.H` | STC 设备头文件；课程 EIDE 配置里留着 `c:/Program Files/Keil_v5/C51/INC/STC` 这一历史路径，换机器需核对 |
| STC-ISP 或 Python + pyserial | 烧录；共享脚本在 [`tools/stcflash.py`](../tools/stcflash.py)，并非打开仓库就自动运行 |
| CH340K USB 串口 | 提供实际 COM 口；连接后再查，不固定为 COM3 或 COM5 |

原课程部分 C/H 的中文注释是 GBK。建仓时只对 44 个文件做了注释编码转换，并同步把工作区编辑器编码设为 UTF-8，便于 GitHub 正常显示；C 语句与字符串内容和课程快照保持一致。构建目录、用户状态和安装器不在 Git 里。
