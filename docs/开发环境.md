# 开发环境与依赖

[首页](../README.md) · [构建与验证](编译与烧录.md)

当前公开仓库的可复现入口包括可移植终端核心的主机测试和独立的 [SDCC MCS-51 目标构建](sdcc-target-build.md)。主机测试需要 Python 3 与 GCC 或 Clang，使用 Fake Platform；目标构建需要 Python 3、SDCC 和 `packihx`，通用 C52 仿真另需 SDCC uCsim。两条路径都不访问真实 RTC、温度传感器或 EEPROM。

`projects/13_环境与时钟信息终端/practice/c51/` 引用未分发的 C51 器件驱动和头文件。仓库不提供可构建的 Keil/EIDE 整体板卡工程、STC 设备支持包、板卡图纸、器件 PDF、烧录脚本或已生成 HEX；SDCC foundation 使用自己的原创入口和诊断适配，不证明这些外设可用或可以直接烧录。

历史学习记录中出现的 EIDE、Keil、COM3/COM5 等信息是旧环境背景，不是当前公开工程的路径、默认配置或已验证操作结果。
