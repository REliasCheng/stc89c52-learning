# 教学板引脚映射

[首页](../README.md) · [硬件平台](03_硬件平台.md)

下表是结合 V1.0 [核心板](../resources/schematics/core-board/SCH_51教学核心版V1.0_2024-05-20.pdf)、[扩展板](../resources/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)以及对应 `src` 宏/位定义核对的**课程板级连接**，并非所有 STC89C52RC 开发板的通用引脚表。

| MCU 信号 | 教学板功能 | 主要实验 |
| --- | --- | --- |
| P0.0–P0.7 | LED、数码管段线、点阵数据的共享口 | 00–05、12–13、16 |
| P1.3/P1.4/P1.5 | 74HC138 数码管位选地址 | 03–05、07–08 |
| P1.0/P1.1/P1.2 | 74HC595 SER/RCK/SCK | 12–13、16 |
| P3.4 / P3.5 / P3.6 | LED / 点阵 / 数码管使能 | 对应显示实验 |
| P4.2/P4.3/P3.2/P3.3 | 独立按键 | 06、09 |
| P2.0–P2.3 / P2.4–P2.7 | 矩阵按键行 / 列 | 07–08 |
| P4.6 | 蜂鸣器 | 08 |
| P3.0/P3.1 | UART RXD/TXD | 14–15、下载链路 |
| P1.6/P1.7 | 软件 I²C SDA/SCL，共享 AT24C02 与 OLED | 16–19 |
| P4.4 | DS18B20 1-Wire | 18–19 |
| P3.7/P4.0/P4.1 | DS1302 SCLK/IO/RST | 19 |

注意原理图有器件使能/反相/缓冲级，不能把“连接到端口”直接等同“高电平点亮”。按实验源码查看具体有效电平、延时和扫描顺序。P3.2/P3.3 既可作按键输入又与外部中断复用，按实际工程使用功能理解。引脚若与实物板丝印不符，应以手上板卡实际版本和原理图为准，记录差异后再接线。
