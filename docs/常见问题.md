# 卡住时先查这一页

[首页](../README.md) · [完整烧录步骤](编译与烧录.md)

**EIDE 提示 `No module named serial`？** 找到上传任务实际调用的 Python，针对同一解释器执行 `python -m pip install pyserial`，再用该解释器验证 `import serial`。不要只看到另一套 Python 安装成功就结束排查。

**Build 了却没有 HEX？** 先确认这次构建确实成功。Keil 00–02 查工程内 `Objects/`；EIDE 工程查自身 `build/Release/` 和 `.eide` 的 `outDir`。仓库不提交历史 HEX，下载后的目录为空是正常的。

**点了 flash 没反应？** `.vscode/tasks.json` 只是调用 EIDE 上传命令；要分开检查 HEX、Python/pyserial、上传脚本、CH340K 端口与板子冷启动。串口监视器占用端口时先关闭。

**该用 COM3 还是 COM5？** 都不是固定答案。插上当前 USB 串口后查看设备管理器的端口号和硬件 ID，再在烧录工具里选同一个端口。

**编译说找不到 `STC89C5xRC.H`？** 检查 Keil C51 的 STC 设备支持与 EIDE `incList`。原课程配置留下 `c:/Program Files/Keil_v5/C51/INC/STC`，只对某些 Windows 安装位置有效。

**亮灯/定时/UART 节奏与资料不同？** 先核对核心板晶振 11.0592 MHz、12T 设置、芯片型号和使能电平，再考虑修改延时或重装值。[引脚表](../hardware/引脚映射.md)只适用于此教学板 V1.0。
