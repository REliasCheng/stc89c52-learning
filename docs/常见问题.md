# 当前公开工程常见问题

[首页](../README.md) · [构建与验证](编译与烧录.md)

**主机测试如何运行？** 从仓库根目录执行 `python scripts/run_host_tests.py --compiler gcc`；需要已安装并在 PATH 中可调用的 GCC。Clang 也可用 `--compiler clang` 选择。

**测试通过是否表示 Keil 构建通过？** 不是。主机测试只编译可移植应用核心和 Fake Platform。C51 入口引用未分发的外部驱动，当前没有完整目标工程或目标构建证据。

**为何没有历史编号工程或 `src/course/`？** 当前公开快照没有分发课程源码和工程文件。旧学习记录只说明历史分析，不能当作本仓库可打开的路径。

**为何找不到 HEX 或烧录脚本？** 本仓库不发布固件 HEX、上传脚本或现成板端项目。不要从历史 EIDE/Keil 说明推断当前快照具备烧录能力。

**RTC、温度或保存失败时状态如何变化？** 核心仅在回调成功且 RTC 数据合法时提交采样；失败保留上次有效值并标记本次失败。保存失败保留脏标记。C51 外部驱动没有完整失败反馈，EEPROM 写后读回也不构成断电持久性证明。
