# 硬件信号与接口分析

[首页](../README.md) · [板级引脚表](../hardware/引脚映射.md) · [学习记录](学习记录.md)

这页把课程工程中的代码动作与教学板 V1.0 图纸对应起来。精确时序、亮度等量化结果以测量记录为准。

## 数码管：选哪一位，与那一位显示什么

在[静态显示代码](../projects/02_数码管/src/course/03-数码管-静态显示/src/main.c)里，`position <<= 3` 后写入 P1 的相关位，P0 再接收 `codes[6]`。对照[扩展板原理图第 2 页](../hardware/schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)，控制路径分为两条：P1.3–P1.5 通过 74HC138 选中一位；P0 的段码经过 74HC245 缓冲后送到段线，P3.6 参与其使能。八位显示共用段线，由位选决定当前驱动的数码管。

到[动态显示代码](../projects/02_数码管/src/course/04-数码管-动态显示/src/main.c)，换位前先清 P0，主循环不断刷新缓冲区。扫描过程每次只选一位，通过连续轮询形成多位显示；亮度和残影程度需要结合实际刷新频率与板端测量判断。

## P0 不是只属于 LED

点灯工程直接操作 P0；数码管用 P0 送段码；点阵也复用这组数据线。板上 P3.4/P3.5/P3.6 参与外设使能。因此，解释 `P0 = ...` 时还要检查当前选通状态，区分程序输出和被使能的目标器件。

## 点阵与 I²C：继续沿调用链追

点阵代码使用 P1.0/P1.1/P1.2 控制 74HC595 的数据、移位时钟和锁存；[静态点阵](../projects/07_点阵/src/course/12-点阵LED/src/main.c)设置图案后，显示刷新由 Timer0/接口层维持。数组位序与实际图案朝向需结合板卡安装方向核对。

EEPROM 和 OLED 共用 P1.6/P1.7。[EEPROM 工程](../projects/09_I2C与AT24C02/src/course/16-EEPROM/src/main.c)沿 `Int_EEPROM` 进入 `Dri_IIC`，OLED 也使用同一组总线线脚。两者需要分别核对设备地址、读写时序和总线占用。

排查时可按“信号引脚 → 使能状态 → 器件接口 → 底层驱动”顺序定位；位序、点阵方向和 I²C 应答等板端细节以实际板卡记录为准。
