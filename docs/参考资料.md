# 参考资料放在哪里

[首页](../README.md) · [来源与许可](../THIRD_PARTY_NOTICES.md)

学习顺序来自尚硅谷 51 单片机课程的 19 个编号工程及 `helloworld`，这里保留了代码快照，但没有上传课程视频、整本教材、安装器、重复压缩包或历史编译输出。课程资料不是我独立创作的内容。

和这块板直接相关的材料保留在 [`hardware/`](../hardware/)：

- 核心板 V1.0、扩展板 V1.0 的原理图；它们是[引脚映射](../hardware/引脚映射.md)和接线说明的依据。
- `datasheets/` 中的 STC89C52、74HC138/245/595、共阴数码管、点阵、AT24C02、DS18B20、OLED/SSD1315 PDF。器件参数请以文件中的原文和实际器件型号为准。
- DS1302 的独立手册不在当前资料中；综合工程中的时序仍要借原厂手册复核。

资料渲染图在 [`assets/images/`](../assets/images/)。它们不是我拍摄的实验照片，也不用于证明程序跑通。许可证边界见[第三方说明](../THIRD_PARTY_NOTICES.md)。
