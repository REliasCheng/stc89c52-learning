# 引脚映射：只适用于本仓库的教学板 V1.0

[硬件目录](README.md) · [扩展板原理图](schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)

这是对照现有核心板/扩展板原理图和实验代码得到的常用连接。**同一个端口可能服务不同模块**，启用电平与外围缓冲级仍要回到图纸和当前代码核对。

| STC89C52RC 引脚 | 扩展板上的用途 | 相关实验 |
| --- | --- | --- |
| P0.0–P0.7 | LED、数码管段线、点阵数据共享 | LED、数码管、点阵 |
| P1.3/P1.4/P1.5 | 74HC138 地址输入，选数码管位 | 数码管 |
| P1.0/P1.1/P1.2 | 74HC595 数据/锁存/移位时钟 | 点阵 |
| P3.4/P3.5/P3.6 | LED/点阵/数码管使能 | 对应显示实验 |
| P4.2/P4.3/P3.2/P3.3 | 独立按键；P3.2 也用于 INT0 | 按键、外部中断 |
| P2.0–P2.3 / P2.4–P2.7 | 矩阵按键行/列 | 矩阵按键、蜂鸣器 |
| P4.6 | 蜂鸣器 | 蜂鸣器 |
| P3.0/P3.1 | UART RXD/TXD | UART、串口下载 |
| P1.6/P1.7 | 软件 I²C SDA/SCL，EEPROM 与 OLED 共线 | AT24C02、OLED |
| P4.4 | DS18B20 1-Wire | 温度、综合时钟 |
| P3.7/P4.0/P4.1 | DS1302 SCLK/IO/RST | RTC 综合实验 |

第一次看数码管时建议同时打开[静态显示的 `main.c`](../projects/02_数码管/src/course/03-数码管-静态显示/src/main.c)：`P1` 选位，`P0` 送段码，P3.6 控制使能。换板、换晶振或改引脚时，不要沿用本表直接接线。
