# 这套教学板

[首页](../README.md) · [引脚映射](引脚映射.md) · [接线说明](接线说明.md)

仓库中的代码针对 STC89C52RC、11.0592 MHz 的 51 教学核心板与扩展板 V1.0。接线与引脚说明均以这两份图纸为准：

- [核心板 V1.0 原理图](schematics/core-board/SCH_51教学核心版V1.0_2024-05-20.pdf)
- [扩展板 V1.0 原理图](schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)

[板卡渲染图](../assets/images/)用于定位接口、数码管、点阵和 OLED；电气连接以原理图和实际板卡版本为准。MCU 与相关器件手册位于 `datasheets/`，来源与许可见[参考资料](../docs/参考资料.md)。

图纸中数码管使用 74HC138 选位、74HC245 缓冲段线，点阵使用 74HC595；核心板的 USB 5 V 和稳压后的 3V6 也分开标注。[信号与引脚对照](引脚映射.md)按 V1.0 板卡逐项整理。
