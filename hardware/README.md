# 这套教学板

[首页](../README.md) · [引脚映射](引脚映射.md) · [接线说明](接线说明.md)

仓库中的代码针对 STC89C52RC、11.0592 MHz 的 51 教学核心板与扩展板 V1.0。两份图纸是接线判断的依据，不是所有 8051 板卡的通用图：

- [核心板 V1.0 原理图](schematics/core-board/SCH_51教学核心版V1.0_2024-05-20.pdf)
- [扩展板 V1.0 原理图](schematics/extension-board/SCH_51教学扩展板V1.0_2024-05-30.pdf)

[板卡渲染图](../assets/images/)可快速认出接口、数码管、点阵和 OLED 的位置，但仍应以 PDF 的电气连接和手上板卡版本为准。`datasheets/` 保留 MCU 与相关器件的 PDF 参考原文；它们不是我的笔记，也不随根目录 MIT 许可证重新授权。资料来源见[参考资料](../docs/参考资料.md)。

图纸中数码管使用 74HC138 选位、74HC245 缓冲段线，点阵使用 74HC595；核心板的 USB 5 V 和稳压后的 3V6 也分开标注。这里按**这套 V1.0 板卡**写硬件关系，不把其他 51 开发板上常见的 74HC573 接法套进来。[信号与引脚对照](引脚映射.md)
