# STC89C52RC 单片机学习与实验

基于 51 教学核心板与扩展板的长期学习仓库：从 GPIO 点灯，逐步过渡到分层驱动、通信与时钟/温度综合实验。实验按实际课程工程顺序保留，说明文档负责把「接线—程序—编译—观察」串起来。当前代码为课程学习快照；**收录不等于逐板验证通过**。

## 编译与烧录

1. 先读 [开发环境](docs/02_开发环境.md)，安装可用的 Keil C51/STC 设备头文件、VS Code/EIDE 和烧录环境。此仓库不捆绑安装器。
2. 对 `00–02` 打开目录内 `.uvproj`，选择目标并 Build；对 `03–19` 在 VS Code 打开对应 `.code-workspace` 或工程目录，用 EIDE 选择 `Release`、`Keil_C51` 后 Build。`03` 使用旧版 `.eide/eide.yml`，其余用 `.eide/eide.json`。
3. 首先确认生成了目标 HEX。连接 USB 串口，核对设备管理器中的 CH340K 端口和线序；核对晶振/12T 设置。用 STC-ISP 选择**当前**串口并按工具提示重新上电下载，或配置 EIDE 的自定义 uploader（需 Python 的 `pyserial`）。不要照抄历史 COM3/COM5。

具体路径、限制和排错见 [编译与烧录](docs/06_编译与烧录.md)、[FAQ](docs/08_常见问题.md)。未连接设备时不要把 Build 成功写成“烧录成功”。
